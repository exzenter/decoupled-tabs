# Project Structure

## Root Files

- `decoupled-tabs.php` - Main plugin file with block registration and asset enqueuing
- `package.json` - npm dependencies and scripts
- `webpack.config.js` - Custom webpack configuration extending `@wordpress/scripts`
- `jest.config.js` - Jest testing configuration
- `jest.setup.js` - Jest test setup file

## Source Directory (`src/`)

### Blocks (`src/blocks/`)

Each block follows the same structure:

```
src/blocks/{block-name}/
├── block.json          # Block metadata and attributes
├── index.js            # Block registration
├── edit.js             # Editor component (React)
├── save.js             # Frontend save function
├── editor.scss         # Editor-only styles
└── style.scss          # Frontend styles
```

**Available Blocks:**
- `tab-area/` - Container block for tab content
- `tab-content/` - Individual tab panel
- `tab-trigger/` - Trigger wrapper block

### Frontend (`src/frontend/`)

- `tabs.js` - Vanilla JavaScript class handling all frontend tab logic
- `tabs.css` - Frontend-only CSS for tab functionality

## Build Directory (`build/`)

Generated by webpack, mirrors `src/` structure:
- `build/blocks/{block-name}/` - Compiled block assets
- `build/frontend/` - Compiled frontend bundle

## Block Architecture Patterns

### Block Attributes

Defined in `block.json` with:
- Type definitions (string, boolean, number)
- Default values
- Enums for restricted values

### Editor Components

- Use `useBlockProps()` for block wrapper
- Use `InspectorControls` for sidebar settings
- Use `InnerBlocks` for nested block support
- Use `@wordpress/components` for UI controls

### Parent-Child Relationships

- Tab Content blocks must be children of Tab Area (`"parent": ["decoupled-tabs/tab-area"]`)
- Tab Area restricts allowed children via `ALLOWED_BLOCKS` constant

### Data Flow

1. Block attributes stored in post content
2. Attributes rendered as `data-*` attributes in save function
3. Frontend JavaScript reads `data-*` attributes to initialize functionality

## Naming Conventions

- **Block namespace**: `decoupled-tabs/`
- **CSS classes**: BEM-style with `decoupled-tabs-` prefix
- **Data attributes**: `data-tab-*`, `data-gsap-*`
- **IDs**: Auto-generated from clientId with descriptive prefixes
- **Functions**: camelCase for JavaScript, snake_case for PHP
